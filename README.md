# 每日讀經 2025–2026（香港聖公會讀經表）— 網站與資料

本專案把《香港聖公會 2026 年讀經表（Lectionary 25–26 中文版）》完整數位化，
並建造成一個「每日讀經閱讀分享」靜態網站，提供：

1. **一天一課**：按讀經表每一天對應一課（2025-11-30 至 2026-12-31，共 397 天）。
2. **文本閱讀**：每課列出聖餐崇拜經課（舊約、詩篇、書信、福音）及早禱／晚禱補充經課，
   並顯示公有領域《和合本》經文全文；主日另提供「互補式／半連讀式」兩套經課。
3. **語音朗讀**：每段經文可用瀏覽器內置中文語音朗讀（Web Speech API，無需連網）。
4. **今日釋經與屬靈教訓**：自動生成今日主題、金句、經課概覽與屬靈教訓。
5. **默想與感受回應**：默想問題 + 可編輯的讀經感受（儲存於本機瀏覽器）。
6. **線上崇拜**：按聖公會《公禱書》流程編排的早禱、晚禱、聖餐崇拜，
   自動插入當日經課與季節祝文。

## 如何運行

網站是純靜態檔案，放在 `site/` 目錄。因為需要 fetch 資料檔，請用 HTTP 伺服器開啟：

```bash
cd site
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000
```

或直接雙擊 `start.command`（macOS）。

## 目錄結構

```
site/
  index.html          今日讀經
  lesson.html         每日一課（?date=YYYY-MM-DD）
  calendar.html       讀經曆
  worship.html        線上崇拜（?date=...&mode=morning|eucharist|evening）
  about.html          本書分析
  css/style.css       樣式（禮儀季節配色）
  js/                 前端邏輯（refs / bible / tts / commentary / liturgy …）
  data/
    lectionary.json   397 天結構化讀經資料（從 PDF 解析）
    refbooks.json     書卷名稱映射
    bible/*.json      和合本（公有領域）66 卷經文
analysis/             PDF 解析與資料管線腳本（Python）
```

## 資料管線

1. `analysis/parse_lectionary.py` — 讀取 PDF（旋轉橫排表格頁、去重疊文字層），
   逐行解析出每天的五欄內容（日期／節日、聖餐崇拜、早禱、晚禱、禮儀顏色等）。
2. `analysis/enrich.py` — 清洗與結構化：季節、顏色、農曆、節氣、
   經課分類（舊約／詩篇／書信／福音）、互補式／半連讀式分組。
3. `analysis/parse_refs.py` — 把「賽2：1－5」「詩119：153－末」等經文引用
   解析成具體章節範圍（4159/4163 條成功解析）。
4. `analysis/convert_bible.py` — 把公有領域《和合本》轉成按書卷的 JSON。

## 版權說明

- 經課引用（書名、章節）取自香港聖公會出版的讀經表，僅供個人靈修與研習。
- 經文採用公有領域《和合本》（1919）；讀經表原文採用《和合本修訂版》，
  兩者字句略有差異，請以正式出版之修訂版為準。
- 崇拜祝文為參考《公禱書》結構改寫的版本，正式崇拜請使用教會頒行禮文。
